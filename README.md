# 骑岸居工作工具箱

纯前端单文件工具箱，双击 HTML 即可使用。所有照片与数据只在浏览器本地处理，不上传服务器。

## 当前工具

| 工具 | 输入 | 输出 |
|---|---|---|
| 交办单 | 整改前 / 整改后照片、问题描述 | 《十总镇长效管理交办单》PPT |
| 安全隐患整改 | 单位信息、隐患前后照片 | Word 四联记录（现场检查记录 / 整改方案 / 隐患治理记录 / 整改复查记录） |

## 直接使用

打开根目录的 `骑岸居工作工具箱.html`（约 787 KB，已内嵌 JSZip、PPT 模板与全部生成逻辑），无需安装任何依赖，也无需联网。

## 从源码重新构建

```bash
cd _网站源码/react
npm install
npm run build
```

构建脚本会读取 `_网站源码/` 下的 `_assets.js`（JSZip + PPT 模板 base64）、`_core.js`、`_tools_lib.js`、`_antd.css`，
把 React 组件打包后生成根目录的 `骑岸居工作工具箱.html`。

- React 18 + antd 5，esbuild 打包，CSS-in-JS 运行时注入，无外部样式文件
- 生成核心（OOXML 手写 PPT / XLSX / DOCX）为原生 JS，不依赖第三方文档库

## 隐私

照片、单位信息、问题描述均不离开本机；抬头单位和上次使用的标签保存在浏览器 localStorage 中。
